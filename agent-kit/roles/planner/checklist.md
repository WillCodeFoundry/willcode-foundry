# Task release checklist

A task is ready only when every line holds.

- [ ] The goal says why, not only what.
- [ ] Every acceptance criterion is testable by QA without a judgement call.
- [ ] No criterion merely restates the goal.
- [ ] Performance, compatibility and security were considered; any that apply
      appear as criteria.
- [ ] "Out of scope" has at least one entry.
- [ ] Every file or pattern in "Context" was opened and exists.
- [ ] "Seams to test" names at least one seam, each with what it catches.
- [ ] Every item under "Terms and decisions" says where it goes (GLOSSARY.md or an ADR).
- [ ] "Open questions" is empty.
- [ ] No `<placeholder>` text from the template remains.
- [ ] A dev could start without asking anything.
- [ ] The task is one task: one session's work, one area of the code, no
      hidden second task.
